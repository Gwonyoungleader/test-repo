# [조교/교수용] 채점 루브릭 (100점)

## 1. 정확한 구현 및 재현성 (20점)
- 실행 가능한 코드, 고정 시드, 실행 방법 명시

## 2. 실험 설계 (25점)
- 변수 통제(노이즈/누락히트/아웃라이어)
- 비교 실험의 타당성

## 3. 성능 평가 (20점)
- 분류: Accuracy/F1/Confusion Matrix
- 회귀: MAE/RMSE/오차분포

## 4. 물리적 해석 (25점)
- 결과를 물리적 관점에서 설명
- 실패 사례 원인 분석의 깊이

## 5. 발표 및 문서 완성도 (10점)
- 전달력, 구조, 시각화 품질

## 감점 기준
- 데이터 누수(train-test leakage): -10
- 실험 재현 불가: -10
- 결과 수치/그래프 불일치: -5

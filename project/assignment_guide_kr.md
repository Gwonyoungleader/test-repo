# [학생용] TPC 기초 ML/DL 4주 프로젝트 안내

## 1) 배경
TPC(Time Projection Chamber)는 입자의 흔적을 히트(hit) 형태 데이터로 관찰하는 검출기입니다.
본 프로젝트에서는 실제 복잡한 검출기 대신, 합성 데이터를 사용해 기본 아이디어를 학습합니다.

## 2) 목표
- 데이터 전처리, 모델 학습, 평가를 수행한다.
- 결과를 단순 정확도가 아니라 **물리적으로 의미 있게** 해석한다.

## 3) 수행 과제
아래 중 하나를 선택하세요.

### A. 분류 과제 (권장)
- 목표: 트랙 이미지가 직선/곡선인지 분류
- 입력: 2D hit map (예: 32x32)
- 출력: 클래스(0/1)

### B. 회귀 과제
- 목표: 트랙의 기울기(slope), 절편(intercept) 추정
- 입력: hit 좌표 집합
- 출력: 연속값 2개

## 4) 필수 실험
1. 노이즈 강도 3수준 비교
2. 누락 히트 비율 3수준 비교
3. 모델 2종 이상 비교(ML 1종 + DL 1종)

## 5) 제출물
- 코드(재현 가능해야 함)
- 6~10쪽 보고서(PDF)
- 7분 발표 자료

## 6) 보고서 필수 항목
- 데이터 생성 규칙
- 모델 구조 및 학습 설정
- 핵심 성능지표 표/그래프
- 실패 사례 3개 이상 시각화
- 물리 해석: "왜 이 조건에서 실패했는가?"
- 개선 아이디어 2개 이상
